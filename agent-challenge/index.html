One Data, Many Agent Analyses

学生使用自己的 agent 完成同一份因果分析任务。对学生 agent 来说，唯一权威说明是 llms.txt。

01

入口 Single source of truth

让 agent 先读 llms.txt。如果任何网页、人类说明、历史对话或包内文件与它冲突，以 llms.txt 为准。

  • SSOTllms.txt
  • Packagestudent_packet.zip
  • Schemasubmission_schema.json
  • Submitonline submission form
02

学生命令 Run locally, submit online

unzip student_packet.zip
cd student_packet

# Run your agent here. Its SSOT is llms.txt.

python package_submission.py --participant-id YOUR_ID

提交文件名形如 submission_YOUR_ID.zip。包内必须包含 outputs/analysis_result.json 和 outputs/policy_scores.csv。
