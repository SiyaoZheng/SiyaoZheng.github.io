时间趋势的干扰

前后变化 ≠ 政策效果。经济发展、环保意识提升等时间趋势混入了变化之中。
那我们找一个没实施政策的城市（比如苏州）做对比，
政策后上海比苏州回收率高，能说明政策有效吗？

上海和苏州本来就一样吗？

两组本来就不一样

上海（实施政策）
2,400 万人口
GDP 3.8 万亿
基础设施完善
≠
苏州（未实施政策）
1,070 万人口
GDP 2.3 万亿
城市结构不同

两座城市本来就不一样，政策后的差异可能是固有差异的延续。

横截面差异 ≠ 政策效果。人口、经济等组间差异被混入了比较之中。
只看前后 ➔ 时间趋势干扰
只比两地 ➔ 组间差异干扰

有没有一种方法，能同时消除这两种偏差？

试着把这两种思路结合起来。

双重差分 Difference-in-Differences

上海变化 9,000 − 3,500 = +5,500
苏州变化 5,000 − 2,500 = +2,500
δ = 5,500 − 2,500 = 3,000 ← 两次做差

* 数据为教学示意

两次做差

第一差
处理组的前后变化
= 政策效果 + 时间趋势
−
第二差
对照组的前后变化
= 只有时间趋势
=
净效果
纯粹的政策效果
时间趋势被消掉了

双重差分的名字就是这么来的，做两次差，同时消除两种偏差。
前提：两组面临相同的时间趋势（见下一页）

回归方程

Yit = β0 + β1Postt + β2Treati + δ(Postt×Treati) + εit
β0基准水平（苏州，政策前） β1 Post时间趋势（两组共同的变化） β2 Treat组间固有差异（上海本来就不同） δ Post × Treat政策的净效果，也就是我们要找的
δ 就是双重差分估计量，即交互项的系数。
这个方程把两次做差的直觉翻译成了可以用数据估计的回归模型。

平行趋势假设

如果没有政策，处理组和对照组的变化轨迹应当平行。
这个假设是否合理，需要靠政策前的历史数据来评估，不能直接证明。

回顾

  • 问题一 只看前后变化 → 时间趋势混入
  • 问题二 只做横截面比较 → 组间差异混入
  • 解法 双重差分 = 两次做差 → 同时消除两种偏差
  • 前提 平行趋势假设 → 两组在无政策时轨迹平行

学以致用

课堂练习

某高校在 A 校区推行了课前预习打卡制度，B 校区没有。
一学期后，A 校区期末均分比 B 校区高 5 分。

如果你来评估打卡制度的效果，你需要哪些额外数据？

用 DiD 的思路，需要知道政策之前 A、B 校区的成绩差距。
如果之前 A 就比 B 高 3 分 → 打卡的净效果 = 5 − 3 = 2 分
当然，这还依赖平行趋势假设，即两校区的成绩增长趋势本应相同。
好的政策评估不是问
政策之后发生了什么

而是问
如果没有政策，会发生什么

这就是反事实思维的力量，也是双重差分法的优美之处。
