AutoResearch

最小化 AutoResearch 示例

一个最小化的 “propose → train → evaluate → keep/discard” 循环实现，产物可直接作为讲课可视化材料。

  • README
  • main.py：实验循环
  • train.py：模拟训练评分过程
  • prepare.py：配置项
  • program.md：实验说明
  • runs/best.json：当前最佳记录
  • runs/progress.csv：表格化执行记录
  • runs/progress.jsonl：逐条执行记录

本地运行命令：python3 main.py --iterations 12 --out runs
