最小化 LLM Wiki 示例

一个最小化 ingest 管道：导入新语料后更新 source / entity / concept / topic 页面，并同步 index 与 log。

  • README
  • ingest.py：增量写入脚本
  • program.md：流程说明
  • index.md：索引页
  • log.md：运行日志
  • sources/demo-note.md（示例源文件）
  • entities/agent.md / entities/wiki.md
  • concepts/agent.md / concepts/pages.md 等
  • topics/topic-demo-note.md

本地运行命令：python3 ingest.py --source raw/demo-note.md
