浏览器版课堂 Notebook

这是课程的 JupyterLite 环境。学生不需要安装 Anaconda，打开网页后即可进入 Notebook。 计算在各自浏览器中完成，所以 20 人左右同时进入也不会把服务器打满。

进入课堂环境 下载课程 Notebook

适合的内容

Python 基础、`pandas`、`matplotlib`、小规模文本分析和课堂演示。

不适合的内容

GPU 作业、大模型推理、长时间训练和需要共享服务器状态的任务。

课后保存

Notebook 和文件默认保存在浏览器本地，下课前请下载 `.ipynb` 或导出数据。

建议使用 Chrome 或 Edge。进入 Lab 后请优先打开 00_data_science_intro.ipynb 开始上课。 第一次启动 Python 内核会比普通网页慢一些，这是正常现象。
