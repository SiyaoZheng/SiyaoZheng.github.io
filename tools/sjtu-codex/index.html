交大致远一号
Codex 一键导入

安装好 CC Switch，填入你自己的交大 API Key，点击下面的按钮。

01

导入配置CC SWITCH

Key 仅在此页面内存中生成本机导入链接。此页面不上传或保存 Key。

浏览器询问时，选择打开 CC Switch，再在弹窗中点击导入。配置名称为交大致远一号 · Codex。

02

导入后，完成首次设置SETUP

交大使用 Chat Completions 接口。请在 CC Switch 中补充以下设置：

  1. 进入 Codex 页，编辑交大致远一号 · Codex，展开高级选项。上游格式选择 Chat Completions，打开支持思考模式和支持思考等级。
  2. 在模型映射中点击添加模型，实际请求模型填写 deepseek-reasoner，上下文窗口填写 250000，保存并启用该配置。
  3. 进入设置 → 路由 → 本地路由，打开路由总开关和Codex开关。连接校园网或交大 VPN后，重新启动 Codex；使用期间保持 CC Switch 运行。

首次在 Codex 中使用 API Key 登录时，填写同一个交大 Key。上述设置依据交大官方 Codex 接入指南。

「复制无密钥模板链接」适合转发。模板导入后需要在 CC Switch 中编辑 API Key，再完成上面的首次设置。

为什么首次还要设置上游格式？

CC Switch 3.20.1 / 3.20.3 的原生链接可带入地址、Key、模型和备注，Codex 导入过程会重建配置；接口转换与模型映射字段需在应用内补充。查看导入实现。

也可下载离线配置包，解压后用浏览器打开其中的 HTML 文件。
